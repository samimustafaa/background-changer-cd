# CD Background Studio

An offline Windows tool to import wallpapers up to 4K, preview them behind selected parts of a Creative Destruction lobby screenshot, preserve the existing player/UI/platform using an editable mask, and export assets.

**Current version is a preview/export editor, not an in-game lobby replacement.** It never injects, patches game archives, or bypasses anti-cheat. Real integration requires documented, permitted lobby asset replacement.

Windows `.exe` builds and the source files are created through the repository's GitHub Actions workflow. See the full README after source bootstrap.
